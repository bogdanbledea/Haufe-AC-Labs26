# Stack my Overflow

A developer Q&A platform — think Stack Overflow, but you're building it yourself.

Over 10 weeks you'll go from zero to a deployed full-stack app with real AI features. Each lab adds a new layer: frontend, backend, database, auth, and then three AI integrations you build yourself, plus one you design on your own.

---

## The finished app

This is what you're building: **[smo-frontend.vercel.app](https://smo-frontend.vercel.app)**

Open it. Try it. Register an account, post a question, generate some tags, see the AI Companion answer. Everything you see there is something you'll build yourself — the same stack, the same features, your own code.

---

## What you're building

A platform where developers can ask and answer questions, vote on the best answers, and get help from an AI that actually reads the question.

Three AI features are built during the labs: tag generation, duplicate detection, and an AI Companion that auto-answers questions in the background. Then you design and ship a fourth of your own. The full spec is in [APPLICATION-SPECS.md](./APPLICATION-SPECS.md).

## How this repo works

New homework is published here after every lab. **Watch this repo** (top right → Watch → All Activity) and GitHub will email you when something new is pushed.

```
homework/
  lab-01-homework.md    ← after Lab 1
  lab-02-homework.md    ← after Lab 2
  ...
```

Each homework file tells you what to build, gives you the context you need, and previews what's coming in the next lab. Written so you can work through it yourself or use it with an AI coding assistant.

## Tech stack

| Layer | Tech |
|---|---|
| Frontend | React 19, React Router, Tailwind CSS, Vite |
| Backend | Node.js, Express |
| Database + Auth | Supabase (Postgres) |
| AI | Groq or Ollama (your choice) |

## Rules

- **Commit often.** At least once per lab session.
- **Read errors before asking for help.** Copy the full error, understand what it says.
- **Use AI as a collaborator, not a copy machine.** If you can't explain the code you just pasted, you don't own it.
